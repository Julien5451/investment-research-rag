# 真实模型评测与失败分析

## 数据与运行范围

- 来源：公开的 Apple 2025 Form 10-K，80 个 PDF 物理页，SHA-256 固定在 [数据集](../eval/dataset.json)。
- 题集：24 条固定开发问题，18 条可回答、6 条应拒答；包含英文及中文问题。
- 模型：`gpt-4o-mini` 和 `text-embedding-3-small`，均实际调用配置中的 OpenAI API。
- 环境：WSL Ubuntu、Python 3.11.16；467 个 chunks，size 1000、overlap 150、top-k 3、相关度阈值 0.35。
- 复核：每次运行保存全部 24 条代理辅助复核 notes，不额外调用 judge 模型；没有独立人工标注或保留测试集。
- 时间：2026-10-30（Asia/Shanghai）。[baseline](../eval/results/baseline/summary.json) 于 03:28 开始，[latest](../eval/results/latest/summary.json) 于 03:36 开始。

## 为什么调整引用匹配

原始校验要求模型的 quote 是 source 原始字符串中的精确子串。对 `a08` 的单独诊断发现，模型保留了原文词语，但把 PDF 提取出的换行变为空格，导致被拒答。其他部分题目也受排版空白影响。

后续修改仅容忍连续空白/换行之间的差异，匹配后通过位置映射返回 source 中的原始连续摘录。数字、标点、大小写和词序不变，不能跨 chunks 拼接引文。问题集、gold、prompt 和检索配置保持不变。

两次结果呈现较少误拒答，但不能据此声称单项修改已经在独立实验中带来固定提升：这是同一开发集上的单次前后观察，真实模型即使 temperature 为 0 也可能返回不同内容。延迟差异同样不作为稳定性能优化结论。

## latest 中剩余的错误

| 问题 ID | 现象 | 对工程的启示 |
| --- | --- | --- |
| `a04`、`a05`、`a12` | 原始 Top-3 未包含标注页，最终误拒答 | 多语言、语义相近的检索仍可能漏掉关键页；应在新数据上评估 hybrid search、reranking 或 query 表达，而非只调低拒答阈值 |
| `a13` | 标注页出现在 Top-3，但检索到的该页 chunk 没有所需财务行 | 页级 Recall 会掩盖 chunk 内容缺失；需进一步评估表格/标题边界与证据级标注 |
| `a11`、`a16` | 仍因不可验证引文而拒答 | 表格线性提取和模型引用习惯仍有限制；不应放宽到数字或词语改写来换取更高回答率 |
| `a06` | 回答了问题的一部分，遗漏明确要求的原因；原因只在 quote 中 | 引用含有信息不等于最终答案完整，因此该题判错；后续可检查多子问题覆盖，但必须在新题上验证 |

## 指标解释中的两个陷阱

**替代页与同页错误 chunk。** 当前每题只标一个 gold 物理页。`a01` 的回答引用了另一个重复同一事实的有效页，却没有命中标注页；这种有效证据在本指标中仍计漏检。相反，`a13` 虽命中标注页，却未包含关键行。因而 72.22% 是标注页召回，不能称为精确答案证据召回。前后比较没有改动既有 gold；后续版本应显式标注等价来源和支持片段。

**100% 拒答率不等于 100% 可靠。** latest 的 6 个不可回答问题都被拒答，但还有 6 个可回答问题被误拒，拒答精确率仅为 50%。正确率 70.83% 中包含这 6 个正确拒答；可回答题正确率为 61.11%。应同时保留这些分母，不能只挑一个看起来高的数字。

## 下一步评测工作

保持这份开发集用于回归，另建多公司、不同排版、独立核验的保留集。优先补齐等价页/证据片段标注，单独评估表格题、多子问题完整性与检索漏失；对候选修改进行多次真实运行后再讨论质量和延迟变化。本次结果不支持生产可靠性、并发吞吐或一般投研准确率的结论。
